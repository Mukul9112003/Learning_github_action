# GitHub Actions - 8 Week Learning Journey 🚀

I am learning GitHub Actions through an 8-week hands-on journey.

The main goal is to understand how GitHub Actions works and how it can be used to automate testing, building, and deployment in real projects.

I am learning by practicing every day and keeping my work in this repository.

## 🎯 Goals

Through this journey, I want to:

- Understand GitHub Actions from the basics
- Learn how workflows work
- Understand YAML syntax used in workflows
- Create and run GitHub Actions workflows
- Automate testing
- Automate builds
- Learn about jobs and steps
- Understand runners
- Work with environment variables and secrets
- Use artifacts
- Understand matrix strategies
- Learn CI/CD
- Practice debugging failed workflows
- Build real-world CI/CD workflows
